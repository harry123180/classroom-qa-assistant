# 課程大綱（範例，請換成你自己的）

## 基本資訊
- 上課時間：每週三 13:10–16:00
- 評分：作業 40%、期中 30%、期末專題 30%
- 遲交規則：每遲交一天扣 10 分，超過 3 天不收

## 每週進度
| 週次 | 主題 | 作業 |
|---|---|---|
| 1 | 環境安裝、print 與變數 | HW1：自我介紹程式 |
| 2 | 條件判斷 if / elif / else | HW2：BMI 計算機 |
| 3 | 迴圈 for / while | HW3：九九乘法表 |
| 4 | list、tuple、dict | HW4：成績統計 |

## 作業繳交方式
上傳 `.py` 檔到課程平台，檔名格式：`學號_HW編號.py`
